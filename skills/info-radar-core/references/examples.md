# info-radar-core 打分示例与边界案例

## 示例1：竞赛报名（脏文本，带全角时间）

**输入**
> 【计算机学院传智杯开发类赛事通知】第九届"传智杯"全国大学生数智创新与AI应用大赛团队赛校内选拔赛通知，报名截止时间为 2026 年 10 月11 日20：00；学院官网通知：https://cs.example.edu.cn/info/1034/19118.htm 【学院团委竞赛中心宣】

**结构化**
```json
{
  "title": "传智杯·数智创新与AI应用大赛（团队赛校内选拔）",
  "type": "竞赛报名",
  "source": "计算机学院 · 团委竞赛中心",
  "url": "https://cs.example.edu.cn/info/1034/19118.htm",
  "deadline": "2026-10-11 20:00",
  "event_date": null,
  "summary": "第九届传智杯AI应用团队赛校内选拔，官网报名",
  "action": "10/11 20:00前经学院官网报名",
  "matched_tags": ["AI/大模型", "算法竞赛", "Python/Java"]
}
```

**打分**（今天 2026-09-25，days_left=16）
- 相关度 38/40（命中 AI+算法竞赛+技术栈）
- 紧迫度 12/35（16天，尚不紧急）
- 价值度 22/25（国家级、AI方向）
- **总分 72**，reason："与你AI/算法竞赛方向契合，团队赛可用上Java/Python，建议尽早组队"
- 分区：🟡 为你推荐

## 示例2：讲座（无 deadline，有 event_date）

输入："计算机学院9月30日办'大模型Agent应用实践'讲座，免报名直接到场"
- `deadline` = null，`event_date` = 2026-09-30
- 紧迫度按 event_date 算（5天后），score≈60 → 🟡
- **注意**：到 9/29（提前1天）应升入 🔴，因当天即过期

## 边界案例

| 情况 | 处理 |
|---|---|
| 相对日期"下周五" | 按运行当天换算绝对日期；周二说"下周五"指下一周的周五而非本周五（如 2026-09-29 周二 → 2026-10-09） |
| 无年份日期"10月11日" | 先按当年解析；若早于今天超 14 天，视为次年（12月说的"3月5日"多半是明年） |
| 只有"10月中旬" | 取该月区间保守值，标 `deadline_confidence: low`，晨报注明"日期待确认" |
| 无任何日期 | `deadline/event_date` 均 null，紧迫度=0，只按相关度进 📋 |
| 一条含多个截止（初赛/决赛） | 取最近的 `deadline` 算紧迫度，`summary` 里注明后续节点 |
| 同一事件多源出现（教务处+学院群） | 合并为一条：`source` 全列、`deadline` 取更早者，只计一次分，只占一个去重 key |
| 命中黑名单关键词 | 相关度直接归 0，不进晨报 |
| 条目已过期 | 移出晨报，seen.json 标 done，此后不再推送 |
| 本期无任何条目 | 只发"📭 今日无新增通知"一句话，不发空模板 |

## 紧迫度分档曲线（urgency 维度满分按权重，默认 35）

取 `d = min(days_left(deadline), days_left(event_date))`，命中最近事件日打分：

| 剩余天数 d | 紧迫度占满分比 | 默认(满分35)得分 |
|---|---|---|
| d ≤ 1 | 100% | 35 |
| d = 2~3 | 85% | 30 |
| d = 4~7 | 60% | 21 |
| d = 8~14 | 40% | 14 |
| d = 15~30 | 25% | 9 |
| d > 30 | 10% | 4 |
| 无任何日期 | 0% | 0 |

> 若 `profile.md` 覆盖了权重，按新 `urgency` 满分同比缩放此表比例。

## 倒计时升级时间轴（以 deadline=10/11 为例）

```
9/25 ──────── 10/7 │ 10/8(提前3天) │ 10/10(提前1天) ── 10/11
   🟡 为你推荐     │   🔴 紧急置顶  │      🔴 紧急置顶(强提醒)
```

## 去重判定示例（以传智杯为例，key = cs.example.edu.cn/info/1034/19118）

| 运行日 | days_left | 判定 | 晨报表现 |
|---|---|---|---|
| 9/29 首次 | 12 | 🆕 新增 | 🟡 完整条目（74分） |
| 9/30~10/7 重跑 | 11→4 | 持续追踪（档位 8-14→4-7 只更新状态，不算升级） | 🔁 一行：传智杯·还剩 N 天 |
| 10/8 | 3 | 倒计时升级（🟡→🔴） | 🔴 完整复推，标"倒计时更新" |
| 10/11 当天 | 0 | 里程碑（当天） | 🔴 置顶，badge"⏰今天 20:00 截止" |
| 10/12 起 | — | 已过期 | 移出晨报，seen.json 标 done |
